Alpha Finder

A personal research system for discovering differentiated Indian microcap businesses. It produces a research queue, never a buy recommendation.

Where things go

  • core/ — the exact type of business and evidence standard we seek.
  • data/universe/company_universe.csv — your pasted company list (CSV exported from Excel is fine).
  • data/documents/concalls/ — earnings-call transcripts/PDFs.
  • data/documents/filings/ — annual reports, results, order wins, capex and other filings.
  • data/research_notes/concall/ — your structured notes from reading calls.
  • data/inputs/ — market-cap audits and valuation scenarios. Manual source URLs are optional fallbacks.
  • data/output/ — generated watchlist and machine-readable results.
  • scripts/ — Python machinery only; you normally do not edit it.

Normal workflow

  1. Download/update the NSE/BSE universe with python -m scripts --build-universe --min-market-cap 100 --market-cap-limit 3500 --segment all. It keeps listed companies above ₹100 Cr and below ₹3,500 Cr for research.
  2. Add original concall transcripts and filings as PDFs.
  3. Record concall notes and audited valuation assumptions. Manual source URLs are only needed when automatic filing discovery misses a document.
  4. Run python -m scripts --analyze-only.
  5. Open data/output/ALPHA_MASTER_WATCHLIST.md.
